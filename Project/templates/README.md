# Work Product and Work Item templates

* **WP type:** Guide
* **Version:** 0.1.0
* **Date:** 2026-11-12

## Work Products

The [Work Product catalog](work-products/README.md) contains reusable
document forms adapted from `kuzmin-machine-ng/Project/templates/`.
Choose a form by purpose, not by filename. Templates are optional scaffolds:
remove inapplicable prompts and do not invent unknown details.

The general [Report](report.md) and [Review](review.md) forms are kept here.
Raw Data, Source Code, Configuration, and Hardware are actual artifacts;
describe their identity, schema, version, and provenance rather than
replacing them with empty Markdown forms.

## Work Items

GitHub Issue forms are in
[`.github/ISSUE_TEMPLATE/`](../../.github/ISSUE_TEMPLATE/). They support
Research, Experiment, Task, Finding, Change Request, and Risk. Work Items
track work; they are not the resulting Work Products. See the
[Work Item policy](../policies/work-items.md).
